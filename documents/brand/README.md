# Brand drafts for the Mascotas app

**Decision (11 November 2026): Petyei is the official application name.** Use the files in [petyei/](petyei/). The other folders remain as discarded candidates for reference.

Draft brand candidates created on 11 November 2026. They are sketches built from simple shapes, not final artwork. Compare them in [compare.png](compare.png) or open [compare.html](compare.html) in a browser.

## Candidates

| Name | Pronunciation | Meaning | Folder |
| --- | --- | --- | --- |
| **Petyei** | "pet-yei" | *Pet* + "yay!": a happy pet. Ends in "i", so the wordmark uses a paw as the dot of the final i. | [petyei/](petyei/) |
| **Petyey** | "pet-yey" | Same idea, closer to the English spelling of "yay". The wordmark is two-tone, with a celebration paw after "yey". | [petyey/](petyey/) |
| Petmui | "pet-mui" | *Pet* + "muy": pets that are very loved. | [petmui/](petmui/) |
| Petmiu | "pet-miu" | Discarded: "miu" sounds like a cat only. | [petmiu/](petmiu/) |

Both Petyei and Petyey work for any animal, read the same in Spanish and English, and use six letters.

## Shared system

- **Icon**: a paw whose main pad smiles, the visual "yay". Light version with forest paw on pistachio; dark version with pistachio paw on forest.
- **Palette**: the official Mascotas light theme. Forest `#2B5735`, pistachio `#D7EC9E`, canvas `#F5F8EE`, ink `#243329`, surface `#FFFFFF`. See the [phase 1 specification](../prompts/mascotas/phase-1-specification.md#official-light-theme).
- **Type**: rounded, heavy lowercase. Nunito ExtraBold or Baloo 2 from Google Fonts are the intended faces; these drafts render with a fallback font. Convert the final wordmark to outlines.
- **Tagline ideas**: *Happy pets, happy people.* · *Adopta, cuida y mueve a tu mascota.*
